## What changed

### Two canons, disjoint by construction

`anime` and `animation` moved out of `CANONICAL_GENRES` into a new `CANONICAL_MEDIA`
(`anime`, `animation`, `cartoon`, `live-action`). The test asserts the two sets share no
member, so a value belongs to exactly one axis or to neither.

`normalise_genre("anime")` now returns `""`; `normalise_medium("anime")` returns `"anime"`.
`normalise_medium("action")` returns `""`. That routing is the whole fix.

### Two maps

`TAG_GENRE` keeps `{tag: (genres, franchise)}` with media stripped out of the genre tuples.
A new `TAG_MEDIUM` holds `{tag: medium}`. A tag can populate one axis, both, or neither:

```
#onepiece   medium=anime      genre=(action, adventure)   franchise=One Piece
#anime      medium=anime      genre=()
#batman     medium=None       genre=(superhero, action, crime)
#capcut     medium=None       genre=()
```

A tag absent from `TAG_MEDIUM` has an **unknown** medium, never an assumed `live-action`.
Most of the bank is silent about medium and inventing one would be a claim the tag never
made.

### Separate fields, separate provenance

`label()` now emits `content_medium` and `content_medium_source` alongside
`content_genre` / `content_genre_source`, plus `medium_declared`, `medium_derived` and
`medium_conflict`. Each axis carries its own provenance entry, and `field()`'s consumer rule
applies to both. The two are never merged into one list.

`content_medium` is a single value, not a list — a clip is one medium.

### The declared tier routes too

A template emits one `Genre:` list, but that list routinely mixes axes:
`"Genre: Anime, Action, Fantasy"` states a medium and two genres. `_declared_axes()` routes
each value by which canon accepts it, so a **declared** medium can never be compared against
a **derived** genre either. Fixing only the derived side would have left the same bug
reachable from the caption.

### The conflict rule compares like against like

`genre_conflict` tests genre against genre. `medium_conflict` tests medium against medium.
A medium-vs-genre pairing cannot flag, by construction rather than by a special case.

## Proof

### The four BL-703 conflicts, reproduced exactly and resolved

`test_bl703_false_positives_resolve` replays the four rows verbatim:

```
#anime      declared=[action, fantasy]                     -> conflict False, medium=anime
#animeedit  declared=[action, fantasy]                     -> conflict False, medium=anime
#animeedit  declared=[action, comedy, fantasy, superhero]  -> conflict False, medium=anime
#animeedit  declared=[action, adventure, fantasy, romance] -> conflict False, medium=anime
```

Each asserts three things: no false conflict, the medium is still recorded on its own axis,
and the declared genres are still recorded. Resolving a conflict by dropping data would pass
the first assertion and fail the other two.

On the full corpus, `coverage()["conflicts"]` is **0**, asserted directly in the corpus test.

### A real disagreement still flags

`test_real_disagreement_still_flags`: a #batman clip declaring `Genre: Comedy` still sets
`genre_conflict = True`, with `content_genre = ["comedy"]` and `superhero` still readable in
`genre_derived`. The flag survived the fix on the case it exists for.

`test_medium_conflict_is_its_own_flag`: an #onepiece clip declaring `Live Action` sets
`medium_conflict = True` and leaves `genre_conflict` False — a real medium disagreement,
detected without contaminating the other axis.

## Limits

- **Medium coverage is 49.9% and is almost entirely one value** (`anime` 174 of 175). That
  reflects the corpus, which was drawn from five anime tags out of twelve. The medium axis is
  currently an anime-vs-unknown flag in practice, not a rich taxonomy.
- **`live-action` is never derived**, only ever declared — no tag in the bank asserts it, and
  assuming it for non-anime tags would be inventing a claim. It appears in the canon so a
  caption that declares it can be routed and compared.
- **Only 1 clip in 351 declared a medium**, so the declared side of that axis is
  essentially untested against real data. `test_declared_medium_routes_to_medium_axis`
  exercises it synthetically.
- **The genre for a franchise tag is still the franchise's genre, not the clip's.** A comedic
  Batman edit tagged #batman derives superhero/action/crime; that is what the declared tier
  and the (now correct) conflict flag are for.
- Still no caller. This remains a pure function that nothing in the funnel invokes.
