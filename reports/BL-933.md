## Limits

- **The missing-attribute sweep is static and one level deep.** It resolves `import X` / `import X as V` and checks `V.attr`. It does not follow `from X import name`, attributes reached through a variable, or `getattr`. A break of those shapes would pass.
- **It also cannot see runtime-only breaks** — a module that imports fine and fails on first call is invisible here. "Every module imports" is a weaker claim than "everything works", and the sweep's name should not be read as the latter.
- **`0 skipped as clone-legitimate` is suspicious and I did not chase it.** I expected some modules to need `config.json` or a key at import; none did. Either the tree is genuinely import-clean or my benign-pattern filter never fired because nothing failed. Both are consistent with 0 import failures, so it does not change the verdict.
- **I committed 148 more lines I did not write**, on the same behavioural grounds as BL-920 — no credentials, not on an import path, coherent — which is a coherence check and not a code review.
- **The 15 explicit-argument sites are reported, not fixed.** Fixing means adding a test that calls each function *without* the argument, and the four `count=` ones are in modules held by other rounds.
- **The cosmetic/costly split is a heuristic over parameter names** and got itself wrong twice. `campaign=''` may well matter more than I have graded it — it is the ledger attribution key.
- **108 suites here against 102 an hour ago and 96 before that**, with 14 rounds in flight. A suite count is a moment, not a property.
