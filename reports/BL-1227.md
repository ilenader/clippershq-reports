## 4. The backspace bytes — shipped, and the gain was credited to the wrong change

`clippershq/meme_finder.py:1217` held **two literal `0x08` bytes** where `\b` was intended.
Inside a raw string they stayed control characters, so the year-range branch demanded a
backspace on both sides and **never matched anything**. BL-1223 found it and broke the file
trying to edit it through the shell. Done as a byte operation instead
(`scratch/bl1227/fix_title_re.py`), with the pattern recompiled and behaviour-checked *before*
the write and a verified readback after. **0x08 count: 2 → 0.**
`_names_a_title("The Sketch Show (2001-2004)")` is now **True**.

### The correction that matters

The brief says **79.66% → 81.40% pooled, 84.62% held out**. Measured against the *shipped*
function over 610 marked pages (`scratch/bl1227/title.json`), with BL-1223's own harness,

**The backspace fix on its own is worth +0.31 points and two pages.** Virtually the entire

## 5. The caption pollution is cleaned — and it is wired this time

BL-1223 measured it, built the cleaner, and left it in `scratch/` saying it belonged "in the
scraper that writes the caption". It now does.

**Why a stored registry and not a live detector.** The discriminator is **codes per handle** —
an advertiser buys ~1 post per page, the scraper writes one paragraph onto 4.7. That is a
*cross-account* fact, and `run_funnel` judges one page at a time; it cannot see that a
paragraph also appears on twenty-five handles it has not fetched. So the proving is done
offline over the whole corpus and what ships is the list it proved:
**`clippershq/data/caption_smear.json` — 41 paragraphs** (12 tier A, 29 tier B) from 681
pages / 7,605 posts. Lookup at scrape time is a dict hit on the caption's prose: no corpus,
no second pass, no cost. `clippershq/caption_smear.py` is the module;
`clippershq/meme_finder.py:posts_for` is the one call site.

`posts_for` gained a `handle` parameter and `run_funnel` passes it, because the **own-handle
guard** — a caption naming the page is that page's own words — is what took the measured rate
down from a first-published 17.77% to the corrected 12.63%. Without the handle it cannot fire.
