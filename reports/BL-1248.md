**A judge that cannot tell "Instagram refused me" from "this page is empty" will write REJECT
rows off an error page.** A detector is cheap and I verified every signal below is readable
from the DOM on a hidden tab, at zero image cost:

```
block/challenge : /try again later|Please wait a few minutes|temporarily blocked|
                  unusual activity|Something went wrong|Restricted/i on body text
login wall      : /Log in to see|Sign up to see/i
private         : /This account is private/i
empty vs unrendered : tiles = document.querySelectorAll('main a[href*="/p/"],
                      main a[href*="/reel/"]').length  -- 0 tiles WITH a rendered
                      header means refused; 0 tiles AND "0 posts" in the header
                      means genuinely empty
```

I ran exactly these on all 9 loads; all returned `false`, and tile counts were 12 on every
page — so the check is live-tested, not proposed.
