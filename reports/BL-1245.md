## 1. THE RULE, IMPLEMENTED AS A MODE

> "Just start the song at 16 seconds and RIDE IT. If the clip is ten seconds, the music ends
> at 26. Just use it from that point. That's it."

`drop_placer.MODE_RIDE` — the bed opens at the marked window's own `start_s` and plays
forward. `action_s` and `drop_offset_s` are **not read**.

```
bed_open = hook.start_s                        # 16.0 — NOT drop − action
bed_end  = bed_open + clip_len + BED_MARGIN_S   # margin 1.0 s
place    = 0.0                                  # the rotation. Always zero.
```

**Why a third mode and not a tweak.** `MODE_CONTINUOUS` already said "nothing is rotated",
and it means it — but it opens at `drop − action_s`, so the opening second moves with every
clip. Same window, same 13.4 s clip:

| `action_s` | MODE_CONTINUOUS opens at | **MODE_RIDE opens at** |
|---:|---:|---:|
| 2.0 | 31.710 | **16.000** |
| 4.2 | 29.510 | **16.000** |
| 9.0 | 24.710 | **16.000** |

His worked example holds exactly: a 10 s clip gives `bed_open 16.0` and audible music ending
at **26.0**. `bed_end` is 27.0 — that extra second is never heard and exists only so
`-shortest` cannot truncate the PICTURE, which is what a bounded audio input did when it
turned a 61.8 s clip into a 5 s file.

**Three gates had to be made mode-aware**, because RIDE legitimately needs none of what they
guard: the `action_s is None` refusal, the `float(action_s)` coercion, and the placeable-range
check. A clip whose motion series cannot be measured now still gets a bed. A `no_drop` window
can ride — it cannot be *aligned*, but nothing is aligned here. A song too short is a
**refusal**, never a wrap, with `place_at_s: None` rather than 0.0.

**Selected visibly, in his own file.** `scratch/songs.json` → `sng_0004` now carries
`"bed_mode": "ride"` plus a `_bed_mode_note` saying what it is and not to delete it. The
render record gained `bed_mode_requested` and `bed_mode_source`
(`"song record scratch/songs.json"`). An **unknown** value raises inside `plan()` rather than
falling back — a silent fallback would render the rotated bed under a config asking for the
ride.

**It cannot be silently undone.** `tests/test_bl1245_ride_mode.py`, 16 tests, green:
the bed opens at 16.0 across clip lengths 8.0–20.0; the opening second does not move with
`action_s` — with a companion test asserting `MODE_CONTINUOUS` *does*, so the first cannot
pass vacuously if the modes ever merge; `place_at_s` and `chain_args(...)[2]` are 0.0;
`chain_args` **raises** if the bed is nudged off the window start; and **`sng_0004` still
carrying `bed_mode: ride`** is itself a test, so deleting the key from his file turns the
suite red instead of quietly re-rotating his audio.
All eight pre-existing placer suites still pass (`test_drop_trim`, `test_drop_placer`,
`test_bl1229_bed`, `test_bl1226_bed_phase`, `test_bl1225_bed_covers_clip`, `test_bed_path`,
`test_bed_joinable`, `test_drop_scan`).
