### 1.1 There is no judging-time call site, and that is a finding rather than an omission

The obvious place to check a brief is where a brief is handed to a judge. **No such code path
exists.** `clippershq/parallel_judge.py` judges with `meme_finder.judge_page`, which is
rule-code carrying no brief — and the repository already says of it, at
`clippershq/meme_finder.py:2447`: *"`parallel_judge` HAS NO PRODUCTION CALLER. Nothing under
`clippershq/` imports it."*

The judge that reads a brief is an **agent**, not a function. Briefs are `.md` files handed to
sub-agents; the verdicts come back as JSON; a scratch script then compares them to his marks.
So the only durable place a leaked brief can turn into a number a human reads is where that
comparison is **rendered** — and that is the one shipped site.

## 2. What was wired

`clippershq/review_sheet.py` renders **"agreement with YOUR marks, before → after"** onto the
sheet. It computed that from the delta and never looked at the brief.

```python
n_before, n_after, excluded, void = scored_agreement(delta, brief_text=brief_text)
```

- **`scored_agreement(delta, brief_text=None)`** — the gate. Scored handles come from the
  delta rows themselves; a page the brief names is **removed from the count**, and if a
  removed page is in the set being reported on the result is **void**.
- **`brief_text` is TEXT, not a path**, for the same reason `guard_scoring` is: a path leaves
  a window in which the brief can be rewritten between the check and the use. `main()` reads
  the file immediately before `build()` computes the agreement.
- **`--brief <path>`** on the existing entry point. No second script — he can open the wrong
  one by accident.
- **The sheet prints `VOID`, never a digit**, when the result is void. A void score is not a
  low score, and a digit would let it be read as one.

### 2.1 "Not checked" is stated as loudly as "leaked"

Three states, three banners, because a number nobody checked and a number that passed a check
are the same digits:

| state | what the sheet says |
|---|---|
| no `--brief` given | *"Agreement **NOT checked** against the brief that produced these verdicts."* |
| brief names a scored page | *"**VOID** — the brief names N page(s) in this scored set: …"* |
| brief is clean | *"Brief checked: it names no page in this set. Agreement below is measured, not memorised."* |

### 2.2 A check that cannot run is not a pass

If `brief_leakcheck` will not import, `scored_agreement` **raises `BriefLeak`** rather than
falling through to an unchecked number. An unavailable checker must never resolve to the same
output as a clean brief — the same reasoning that makes `backup_prune` exit when
`git ls-files` fails. Held by `test_an_unimportable_checker_raises`, which patches
`builtins.__import__` to make the import fail for real.
