## What was wrong, and the three-part fix

`_drop_factual_blocks` deletes a factual field from its marker **to the next known marker**. `Summary` and `Why Watch` were not in the vocabulary, so they did not stop the deletion — `🎭 Starring:` ran all the way down to `🏆 Rating:` and took the Summary with it.

**1. Added to `TEMPLATE_FIELDS` as terminators**, following the `Hashtags:` precedent BL-694 set (parsed purely so it stops a block):

```python
"summary":   ["Summary", "In short", "Plot Summary", "TL;DR"],
"why_watch": ["Why Watch", "Why Watch It", "Why You Should Watch", "Why It Works"],
```

**2. Marked KEPT, not factual.** `FACTUAL_FIELDS` now subtracts `SECTION_HEADER_KEYS` as well as `storyline`/`themes`. This is the part that separates them from `Hashtags:` — a cast list is dropped because it is proper nouns; a Summary is kept because it is the plot in sentences. Kept set is now `storyline, summary, themes, why_watch`.

**3. `?` as a delimiter, scoped to these two labels only.** `🔥 Why Watch?` ends in a question mark, and `_FIELD_LINE` requires a colon. Rather than relax the delimiter across the whole closed vocabulary — where a rhetorical "Genre?" or "Rating?" in prose would then read as a marker and silently truncate a real block — a second pattern `_SECTION_LINE` accepts `[:?]` over the section aliases alone, and is tried *after* the colon pattern.

**A fourth change fell out of the third.** The bare-header removal was a regex anchored at `^\s*`, so it could only match an undecorated line — but every real farm header is emoji-prefixed (`📝 Summary:`, `🔥 Why Watch?`). It is now `_drop_kept_field_markers`, which strips decoration per line exactly as `_field_marks` does, and removes **only value-less** marker lines. `Storyline: he loses everything` keeps its text, because the prose shares the line with the label.

## The re-measurements

### BL-694's 42 committed labels: unmoved

Re-run at the same default margin against `tests/data/caption_valence_labels.jsonl`:

| | accuracy | macro-F1 |
|---|---|---|
| BL-694 published | 0.786 | 0.643 |
| **after this fix** | **0.786** | **0.643** |

Per class, also identical: positive P=0.952 R=0.800 F1=0.870 (published 0.95/0.80/0.87); negative 0.750/0.800/0.774 (0.75/0.80/0.77); neutral 0.200/0.500/0.286 (0.2/0.5/0.29).

**The 78.6% baseline holds.** That is the expected result and it is worth stating why: those 42 labels are drawn from cluster-B and untemplated shapes, which is exactly the population BL-694 said its figure described. The fix reaches cluster-A, which the labelled set does not cover — so the correct outcome was *no change here*, and that is what happened.

> Honest note on the harness: the comparison script initially printed "BASELINE MOVED" with deltas of −0.000 and +0.000. That was the script comparing a full-precision 33/42 = 0.785714 against the published 3-dp 0.786 and failing an exact-equality test. The true difference is 0.000286 — rounding, not movement.

### Template detection: zero side effect

Adding vocabulary can only raise the field count, so `is_templated` could in principle flip captions from untemplated to templated and change downstream routing. Measured across 671 captioned posts:

| | templated |
|---|---|
| with the new fields | 108 |
| without them (pre-fix) | 108 |
| **newly classified** | **0 (0.00%)** |

No caption crossed the `TEMPLATE_MIN_FIELDS=3` boundary because of this change — cluster-A captions already carried three or more factual fields. The detection surface is untouched.

## What this does not fix

**Cluster-A valence is now measurable, not validated.** Coverage went from 5.2% to 66.5%, which means the scorer finally sees the prose — but there are **no hand-labels for cluster-A captions**, so its accuracy on that shape remains unmeasured. BL-694's 78.6% still describes cluster-B and untemplated only. Labelling ~40 farm captions is the obvious next step, and until it happens no accuracy claim should be attached to farm-page valence.

The remaining 33.5% dropped on cluster-A is the factual block working as designed (Starring, Rating, Original Run, Streaming, Format, Credits) plus hashtag walls.
