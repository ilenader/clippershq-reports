## 1. The grep fragility — resolved by AST

`tests/test_quality_score.py:624` was two regexes over `_real_quality_score`'s source:

```python
_m = _re.search(r'notes\.append\("recency-unknown"\)', _src)
_branch = _src[_src.rfind("else:", 0, _m.start()):_m.end()]
check(not _re.search(r"score\s*-=", _branch), ...)
```

Two failures, one cause — **a text search cannot tell code from prose**:

- a comment inside the branch mentioning a deduction (`# no score -= here`) fails the check;
- when the first regex missed, `_m` was `None` and `_m.start()` raised **`AttributeError: 'NoneType' object has no attribute 'start'`** — the import-time crash MEMEBOT-031 hit.

Replaced with an AST walk that finds the `if`/`else` whose body appends the note, then asks whether any `AugAssign` in that body subtracts from `score`. **Comments do not exist in an AST**, so the question cannot be confused by one, and a not-found branch is now a **failed check** rather than a traceback.

**VERIFIED on three planted shapes:**

| planted source | old text grep | new AST check |
|---|---|---|
| comment mentioning `score -=` in the branch | **would FAIL** (false alarm) | `subtracts=False` ✓ |
| a real `score -= 5` in the branch | would FAIL | `subtracts=True` ✓ |
| branch absent entirely | **AttributeError** | `NOT FOUND` → reported as a failed check ✓ |

`tests/test_quality_score.py` exits **0**, and both new checks report `ok`. The AttributeError is gone by construction: nothing calls `.start()` on a possibly-`None` match any more.

## Honest limits

- **Item 2 was not my work.** BL-897 fixed `own_paths` while this round was open; I verified the result rather than writing it.
- **The suite is not green and I am not calling it green.** One red, attributed to a live round's file, verified not to involve anything I touched — but attribution is not diagnosis. I did not read BL-899's changes.
- **The `--enrolling` check must be run to help.** It is a command, not a hook; nothing forces it before a commit. Wiring it into `wip_commit.py` or a pre-commit hook is the obvious next step and that file was free — I left it, having already expanded scope twice this session.
- **The config key count moved under me** (162 → 161). Campaigns are byte-identical as required, so the round's contract holds, but the file is not static and I did not chase what changed.
- **The AST check is narrower than the grep it replaced.** It asks specifically about `score -= …` inside the note's branch. A deduction expressed as `score = score - 5`, or moved into a helper, would pass. That is a deliberate trade — a precise question that can be answered correctly beats a broad one that cannot.
