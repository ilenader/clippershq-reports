## 1. `publish_report.exists_on_remote()` — it did not fail to block a publish, it authorised one

```python

return bool((r.stdout or "").strip())          # git failed -> "" -> False -> "not there"
```

A git failure returned `False`, which the caller reads as *"no report by that name on the remote"* — and proceeds. `CONVENTION.md` records **three reports lost** to exactly that ID collision, and the check has **prevented three more** since it shipped. This is the guard that works, with a hole in it.

It now raises `Refused`. Proven with git returning 128:
