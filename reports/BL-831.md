## 2. Why so few? Two causes, and neither is the tag map

```

clippershq/clip_runner.py:209:    rec = cg.label(tag=None, caption=cap)
```

## 3. Expanding the vocabulary — measured, not guessed

I parsed the declared genre line from every caption and ran each token through
`normalise_genre` / `normalise_medium`:

```
clips with a DECLARED genre line : 200
distinct declared tokens         : 83
token instances                  : 564
  recognised                     : 409 (72.5%)
  DISCARDED                      : 155 (27.5%)   across 60 distinct tokens
```

**27.5% of the vocabulary the accounts actually write is thrown away.** The discards split
cleanly into two groups that need different treatment:

### Group A — decomposable (78 instances, 25 tokens)

Compounds containing a word already canonical. These need **splitting**, not new vocabulary:

| token | n | decomposes to |
|---|---:|---|
| family comedy | 11 | family + comedy |
| romantic comedy | 8 | romance + comedy |
| teen drama | 8 | drama (+ audience: teen) |
| historical drama | 6 | drama + historical |
| animated sitcom | 6 | **medium: animation** + sitcom |
| crime drama | 5 | crime + drama |
| adult animation | 5 | **medium: animation** (+ audience: adult) |
| romantic drama | 4 | romance + drama |
| dark fantasy | 3 | dark + fantasy |
| legal drama, war drama, workplace comedy, psychological drama, period drama, satirical comedy, satirical sci-fi… | 1–3 each | same pattern |

`animated sitcom` and `adult animation` are the ones that **prove the medium/genre split is
right**: they carry a medium *and* a genre in one token, and collapsing them would recreate
exactly the false conflicts BL-703 separated.

### Group B — genuinely new vocabulary (77 instances, 35 tokens)

| proposed genre | measured n | note |
|---|---:|---|
| **war** | **14** | the single largest discard |
| **mockumentary** | 9 | arguably a FORMAT; see below |
| **biography** | 8 | + "biographical drama", "true story" |
| **mystery** | 6 | |
| **procedural** | 5+3+1 | "police procedural", "legal", "firefighter procedural" |
| **martial-arts** | 3 | |
| **sports** | 2 | in the brief; supported but thin |
| **coming-of-age** | 2 | + "young adult", "youth romance" |
| **parody** | 2 | distinct from `satire`, already canonical |
| **slice-of-life** | 1 | anime-adjacent, defensible |

**Recommended additions to `CANONICAL_GENRES`:** `war`, `mystery`, `biography`, `historical`,
`sports`, `coming-of-age`, `martial-arts`, `procedural`, `parody`. That is **9 additions
covering ~50 of the 77 unrecognised instances**, each with a measured count behind it.

**Not recommended without more data:** `slice-of-life`, `time travel`, `emotional`,
`bl-themed`, `mafia`, `dystopian` — 1 instance each. Adding a canonical value on n=1 is how a
vocabulary becomes noise.

**A judgement call worth flagging:** `mockumentary` (9) is the third-largest discard and is a
*form*, not a subject. It belongs on the medium axis beside `animation`/`live-action`, or on a
third axis. Putting it in `CANONICAL_GENRES` would repeat the anime mistake in a new place.

**Documentary** is in the brief and already canonical; it appears 0 times in the declared data,
which is consistent with a meme/clip pool.

## 4. Franchise — 22.9%, and the missing 77% are genuinely absent

**Current fill: 141 / 617 = 22.9%.** BL-807's 65% does not reproduce on this population; the
pool has roughly quadrupled since, and the new accounts do not write titles.

**The remaining 476 are not recoverable by a better pattern.** I ran a permissive title matcher
(`title|judul|movie|series|show|film|anime|nombre`, emoji-prefix tolerant) over every
franchise-less caption:

```
clips WITHOUT franchise            : 476
 ...that carry ANY title-style line:   2  (0.4%)
```

**Genuinely absent, not unparsed.** A better regex buys nothing here; only a different content
source (OCR, vision, audio fingerprint) would.

**But the 22.9% that IS extracted is dirty**, and that is fixable:

```
'Judul: A Little White Lie'         <- Indonesian "Title:" left inside the value
'<zero-width>Judul: A Little White Lie'   <- plus an invisible char, so it dedups SEPARATELY
```

15 captions contain a zero-width character. The same film appears as two franchises.

## 6. Provenance — the split is being collapsed **today**

The brief asks that declared and derived not be collapsed. **They already are.**

```
clip_library.py:252   put("content_genre", content_genre, DERIVED)
```

Hard-coded. Measured over the library: **provenance `derived` on 176 of 176 clips, `declared`
on 0** — while 172 of those 176 came from a caption the account itself wrote. **Every declared
genre in the library is mislabelled as derived.**

`content_genre.py` does not have this problem — `label()` returns `genre_declared`,
`genre_derived` and `genre_conflict` as separate fields. The information exists and is discarded
one layer later, at the `put()`.

Demonstrated on a real caption shape:

```
caption: "Title: Gladiator / Genre: Action, Drama, Historical"
label() genre_declared : ['action', 'drama']      <- 'historical' silently dropped
stored provenance      : derived                  <- but it was DECLARED
```

That one example carries both defects: the lossy vocabulary (§3) and the provenance collapse.

## Ranked, by what an editing bot gains per unit of work

1. **Stop hard-coding `DERIVED`** (§6) — one line, restores a distinction the layer below
   already computes, and makes every existing row honest.
2. **Split compounds before normalising** (§3 Group A) — 78 instances recovered with no new
   vocabulary, and it is what makes `animated sitcom` land on both axes correctly.
3. **Add the 9 measured genres** (§3 Group B) — ~50 instances, each with a count behind it.
4. **Strip zero-width characters and non-English label prefixes** (§4) — 15 captions, and it
   collapses duplicate franchises.
5. **Parse the emoji-prefixed shape** (§5) — unlocks 81.5% of field-lines, and with it `imdb`
   (26.9%), `starring` (19.8%) and `rating` (19.8%).
6. **Either wire `tag=` or delete the tag map** (§2a) — 45 entries of dead code that three
   rounds have now reasoned about as if it were live.

## Limits

- **617 clips, 66 accounts, one snapshot.** Two accounts are 34% of the corpus, so the genre
  distribution is weighted toward `loste1980` and `movies.avengers`.
- **The 27.5% discard rate is over declared-genre tokens only** (564 instances from 200 clips),
  not over all clips.
- **Token splitting is a regex on `,` `/` `•` `·` `;` and dashes.** A caption using an
  unanticipated separator reads as one long token and lands in "discarded"; a few entries in the
  Group B tail (`- war`) are that artefact, not real vocabulary.
- **Group A/B classification is mechanical** — "contains a canonical word" — so
  `dark fantasy` counts as decomposable because `dark` is canonical, which is arguably the wrong
  reading of that term.
- **BL-807's 65% franchise was not re-derived on its own population**, only measured on today's.
  Both figures can be right.
- **I did not check whether any consumer reads `content_genre`** — the ranking question is
  outside this brief.

## Method

Read all 34 shards of `clip_library/` through the module's own `clip_library.iter_lines` and
`field()`, deduplicating by `clip_id` (755 → 617). Genre, medium, franchise and provenance were
read via the shipping accessor so absent/null/populated stay distinguishable. Caption field-lines
were classified by two regexes — plain `^Label:` and symbol-prefixed — with labels NFKD-normalised
before counting, and counted per **clip**, not per line. Vocabulary loss was measured by
splitting every declared genre line and passing each token through the live
`content_genre.normalise_genre` and `normalise_medium`. The provenance collapse was reproduced by
calling `content_genre.label()` on a real caption shape and reading `clip_library.py:252`
directly. Zero paid calls, $0, nothing written outside the session scratchpad.
