# BL-1014 — evaluating claude-video (/watch) as an audit tool

**Recommendation: ADOPT FOR A NARROW SIGNAL — frame extraction for viewing audits. Do not
adopt as a labeller, and do not expect it to fix audit repeatability.**

**The one number: on the audit question this project fails most often — "does the video carry
audio at all" — the tool's report is 0 for 11 of 11 hand-labelled rows.** Not because it gets
it wrong: because its report does not carry the answer. A silent render and a render with a
music bed produce **byte-identical report bodies**.

**And the finding that matters most came from my own harness.** My first duration score was
56%. It was wrong for exactly the reason the four prior harnesses were wrong — an uncontrolled
join, not a bad detector. §5.

---

## 1. What it pulls in, and what leaves the machine

Cloned to a scratch dir **outside** the private repo. 36 files, 9 Python scripts.

**Zero third-party Python packages.** Every import across the skill is stdlib or its own
modules: `argparse json math mimetypes os pathlib platform re shutil ssl subprocess sys
tempfile time urllib uuid` plus `config download frames transcribe whisper`. No Pillow, no
requests, no numpy.

**External binaries:** `ffmpeg`, `ffprobe`, `yt-dlp`. For a **local file** `download()`
dispatches to `resolve_local()` and **yt-dlp is never invoked** (`download.py:170-172`) — so
the local-file path needs ffmpeg only, which we already have.

### Every network egress in its own code

| endpoint | where | when |
|---|---|---|
| `api.groq.com/openai/v1/audio/transcriptions` | `whisper.py` | Whisper fallback only |
| `api.openai.com/v1/audio/transcriptions` | `whisper.py` | Whisper fallback only |

Everything else matching a URL is documentation (`brew.sh`, the repo, two API-key pages) or a
literal example (`youtu.be/abc`). `urlopen` appears **only** in `whisper.py`. **No telemetry,
no analytics, no phone-home.**

### The gate that matters

`watch.py:239` — Whisper runs only if **all** of: no captions parsed, `--no-whisper` absent,
a video path exists, the file **has an audio stream**, *and* `load_api_key()` returns a key
from env or `~/.config/watch/.env`.

Verified on this machine: `GROQ_API_KEY` unset, `OPENAI_API_KEY` unset, no `.env` file. **With
no key configured there is no egress path at all**, even without the flag. I passed
`--no-whisper` on every run anyway.

**Captions-only must still be the enforced default here**, because the failure mode is
silent: add a key for one experiment and every subsequent audit uploads our clients' and
leads' video audio to a third party.

### Where it writes

- Work dirs in **system temp** (`…\Temp\watch-<random>\`), one per invocation, 15 created
  during this evaluation. Not its own directory, not the repo — worth knowing, since they are
  not cleaned up automatically.
- Config would go to `~/.config/watch/.env` — **outside its own directory**. Not created here
  (`setup.py` never run).
- **Nothing was written into the private repo.** Confirmed with `git status`.

## 2. On our own renders

Ran against local `final/` renders only. Never YouTube, nothing uploaded.

| detail | wall clock | frames from a 13.2s render |
|---|---:|---:|
| `transcript` | 0.50s | 0 |
| `efficient` | 1.33s | 6 |
| `balanced` | 3.15s | 13 |
| `token-burner` | 3.45s | 13 |

**The transcript half is inert for us.** Our renders carry no caption track, so
`Transcript: none available` on every one. With a key configured, Whisper would transcribe a
**music bed with no speech**. The tool reduces, for this project, to scene-aware frame
extraction.

### What the frames actually answered

Reading frames does answer the visual audit questions, well. From a single frame of
`3618524478543487669…` I could state, unprompted:

- the burned caption reads *"@Moviezar posts the best movie memes on instagram daily Spidey
  Sense, also known as Spider-Sense, is a special ability.."* — **truncated mid-sentence**;
- it is **the source's** promo line spliced onto an encyclopedia definition, not ours;
- the source page's avatar and handle are **embedded in the frame**;
- there is dead canvas top and bottom.

The hand label was *"incoherent caption + silent"*. **I confirmed the caption half from one
frame and could not see the silence at all.**

A second case, `3926065738654151637…`, hand-labelled *"58s, caption opens ':-', another page's
watermark"*: from one frame I read the `":-"` opener, the truncation, a rival's `RIVEN-E…`
watermark burned into the picture, and the square-source dead canvas. Everything except the
duration, which the tool's own header supplies.

## 3. Agreement against hand labels — and what could not be scored

Against `ground_truth/clip_verdicts.json` (61 rows, 60 clips) and never against another
detector. **All 61 rows have a local render.**

| question | n | result |
|---|---:|---|
| duration | 27 | **100%** within 1.0s — *when the correct render is chosen*; 56% with an arbitrary one (§5) |
| audio present | **11** | **0** — the report never states it (`watch.py:265` prints to stderr) |
| caption complete / whose text / watermark | 2 hand-read | agreed with the hand label on the visual half of both |
| postable | — | **not scorable, and reporting a number would be dishonest** |

**Why "postable" is not scorable.** The set's own `_limits` says never pool its three judges,
and their bars are incompatible: BL-950 `0/24` postable, MEMEBOT-074 `3/30`, MEMEBOT-086
`5/7`. Pooled, the verdicts are `no 50 / post 8 / fix 3` — **"always answer no" already scores
82.0%.** Any agreement figure near 82% would be measuring the class imbalance. With 8
positives across three judges, this set cannot support the question.

**The caption/watermark row is n=2 and is labelled as such.** Auditing 60 renders by eye is a
viewing audit, not an evaluation of a tool, and inventing a larger number here would be the
exact failure this brief is about.

## 4. Cost

| | wall clock | dollars |
|---|---|---|
| /watch, captions-only, local | 1.3–3.5s per video | **$0.0000** — zero paid calls |
| an audit today | a hand-built harness each time | ~$0.008–0.023 for 21–30 renders |
| vision labelling | — | ~$1.50–2.12 per 1,000 clips |

**The tool's marginal dollar cost is zero** in the mode we would use, because ffmpeg is local
and Whisper is off. The real cost is **reading**: `efficient` emits ~6 frames per video, so a
30-video audit is ~180 images for the agent to read.

**It is not a labelling replacement, and the arithmetic is not close.** Vision labelling runs
~$1.50–2.12 per 1,000 clips — about **$0.0018 per clip, one call, one structured answer**.
/watch produces no label at all: it produces frames a model must then read, at 6 images per
clip. For 2,661 clips that is ~16,000 image reads to replace a $4 job. **Do not use it for
labelling.**

## 5. Would a standard tool have prevented the four false-verdict harnesses?

**No — and this round demonstrated why on itself.**

My first duration score was **56% (15/27)**. The mismatch list opened with a clip hand-labelled
55.0s that measured 15.6s. That gap is not the tool: **a clip has up to 26 renders across
different work dirs**, and my harness took `renders[clip][0]` — an arbitrary one. Choosing
*any* render of the same clip: **27/27, 100%.**

So my harness produced a confidently wrong number by the same mechanism as:

| harness | its false verdict | mechanism |
|---|---|---|
| glyph detector | 20/30 broken,真 4 | wrong threshold on the right object |
| unbounded lag search | 0.94 on an **absent** track | search space too large for the evidence |
| non-white bounding box | counted caption glyphs as picture | wrong object measured |
| mid-word detector | passed *"the young c"* | rule too weak for the claim |
| **this round** | **56% duration agreement** | **wrong artifact joined** |

`/watch` would have prevented **none** of them. Every one is a defect in the harness *around*
the measurement, not in the frame grab or the ffprobe call. The tool's ffprobe duration was
correct in all 27 cases; my join was wrong in 12.

**The ground truth cannot fully close this either:** `judged_at_commit` is `unknown` on **24 of
61 rows**, so for those the specific render judged is unrecoverable. A verdict that cannot be
tied to an artifact cannot be re-measured against one.

What *would* have prevented these: a per-item check against a known answer before the
aggregate is believed — which is a discipline, not a dependency.

## 6. Recommendation

**ADOPT FOR A NARROW SIGNAL: frame extraction in viewing audits.** It replaces a hand-built
ffmpeg contact-sheet step (BL-963 built one; MEMEBOT-098 built another) with one command, zero
dependencies beyond ffmpeg, zero dollars, and scene-aware selection that is better than the
fixed 1 fps we have been using. Always with `--no-whisper`.

**DO NOT ADOPT AS A LABELLER.** ~$0.0018/clip and one structured answer beats 6 images/clip
and no answer, by three orders of magnitude.

**DO NOT EXPECT IT TO FIX AUDIT REPEATABILITY.** It answers none of the four failure modes,
and this round reproduced a fifth while evaluating it.

**Two conditions on adoption:**

1. **`--no-whisper` must be enforced, not remembered.** A key added for one experiment sends
   our video audio to Groq or OpenAI, silently, on every later run.
2. **Audio presence must come from elsewhere.** The report cannot distinguish silent from
   music-bearing, and that is this project's most-measured defect class (BL-950: 0 of 25
   carrying the song). One `ffprobe` line covers it; do not let the tool's silence on the
   subject read as an all-clear.
