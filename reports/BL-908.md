## 1. The fix: `clippershq/stillness.py` invokes nothing

BL-903's poller reported **zero rounds in flight** while eleven claim files sat on disk, because `tools/claim.py` was mid-edit, raised `SyntaxError`, printed nothing, and `grep -c` read zero matches as zero rounds.

**The bug was never in `claim.py`.** It was asking a *program* a question the *filesystem* could answer. In a tree with a dozen live rounds, every tool is also somebody's edit target — and this is the third instance:

| tool | what happened | round |
|---|---|---|
| `run_all.py` | committed mid-edit, `NameError`, suite unrunnable | BL-871 |
| `clip_library.py` | edited by two rounds at once | BL-863 |
| `claim.py` | mid-edit, `SyntaxError`, reported zero rounds | BL-903 |

The new module reads `.claims/*.json` with `glob` and walks the tree with `os.walk`. **There is no subprocess in it**, and that is checked by AST rather than asserted in prose:

```python
def test_the_module_shells_out_to_nothing(self):
    """The strongest guarantee available: it cannot be broken by an edit to a tool
    because it does not invoke one."""
```

## 2. A crashing tool is now loud: `run_checked()`

For every *other* check that must parse a program's output. It refuses to return stdout unless the process exited 0:

```
subprocess.run(...).stdout on a crashed program is ''
  -> '' parses to zero rows
  -> zero rows reads as "nothing wrong"
```

The distinction it enforces is the one that matters: **empty-because-nothing-found is a real answer and is returned; empty-because-it-crashed is not an answer and raises `ToolFailed`.** Six tests cover it, including the exact BL-903 shape — a Python file with an unterminated docstring, which prints nothing to stdout and exits non-zero.

## 3. The sweep, ranked by what each would wave through

AST-based, not textual: it finds subprocess calls whose **output is consumed while the return code is not**. 57 hits total; 53 are one-off `scratch/` scripts. **Four are in production code:**

**A correction to my own first reading.** I initially expected a false *pass*. It is a **skip** — the consumers do guard with `skipTest`. **`clip_library/` has been appended to continuously for six-plus hours** by a succession of labelling rounds, each releasing into the next. Over BL-903's hour it moved at **29 of 30 samples**. Source files were still for **six minutes at best**, and the library moved inside even that window.

`stillness.py` fingerprints the library **separately from source** for exactly this reason, and a test pins the consequence:

```python
def test_a_live_library_walk_blocks_even_when_source_is_frozen(self):
    """The constraint that has never cleared: source still, library appending."""
```

**Stillness will not arrive on its own.** It needs the operator to stop starting rounds; no round can force it by waiting, and none should force it by writing to a tree it does not own.

## Honest limits

- **`stillness.py` is a library, not yet wired into anything.** It is what a future stillness brief should call instead of shelling out, but no round uses it yet. Wiring it into the poller a future round would run is a separate change.
- **The three ranked sweep sites are reported, not fixed.** Rank 1 is in `tests/test_claims_manifest.py`, which BL-889/BL-890 have been editing today; rank 2 and 3 are in files other rounds hold. The fix in each case is one `run_checked()` call, and the function now exists for them.
- **I did not run the full `run_all.py` suite** — the tree has 14 rounds in flight and BL-884/BL-891/BL-903 all established that an aggregate number under those conditions cannot distinguish a defect from a half-edited import. The five suites this round touches were run individually and pass.
- **`run_checked()` has no in-repo callers yet.** It is deliberately unused by `stillness.py` itself, because *not invoking anything* is a stronger guarantee than checking an exit code. That means its value depends on other rounds adopting it.
- **The fingerprint uses mtime and size, not content.** A write that restores a file byte-for-byte still reads as a change. That is the conservative direction — it can say "not still" when the tree is fine, never the reverse.
