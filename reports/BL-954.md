## 2. Proving it — a forced vendor error, end to end

**VERIFIED** on a temp library through the real `record_failure` path:

```
BEFORE any failure    : selectable=True  attempts=0  err=None
after a forced 502    : selectable=True  attempts=0  err='openrouter HTTP 502'
after FOUR 502s       : selectable=True  attempts=0  err='openrouter HTTP 502'

  vision_last_error         = openrouter HTTP 502
  vision_last_error_kind    = transport
  vision_transport_failures = 4          <- the spend IS visible
  vision_attempts           = 0          <- retirement budget untouched

after 2 CONTENT faults: selectable=False attempts=2   <- correctly retired
```

**One nuance the brief's phrasing hides, and it is worth being exact about.** "Confirm the clip is not re-selected" is right for a **content** fault and wrong for a **transport** one. A 502 is transient, so the clip *should* stay selectable — that was BL-949's whole point. What the record buys is not retirement, it is **visibility**: the spend survives the run, `vision_transport_failures` counts it, and a clip failing transport forever is now something you can see rather than something that silently re-bills. The "not re-selected" half is proven by the content case: two content faults, retired.
