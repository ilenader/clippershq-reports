**A methodological catch worth recording.** My verification printed `True` for four of the five rungs, which looked like the conversion had landed:

```
  DECLARED  owner<-lib: True      DERIVED  owner<-lib: True
  MEASURED  owner<-lib: True      ABSENT   owner<-lib: True

```

That is **Python interning short string literals**, not shared ownership. `READABLE` is a tuple, is not interned, and correctly reports `False`. **An identity test on short strings cannot prove a single definition** — only the tuple does.
