## 2. `motion` is now a stored, declared field

`clippershq/clip_motion.py` fixes the definition that three rounds had been copying:

> the **median** absolute frame-to-frame difference of **12** frames sampled evenly across the
> clip, each scaled to **64 px** wide, 8-bit greyscale.

Median, not mean, so one hard cut cannot make a still graphic look like a clip. `mb089_watch`,
`mb095_watch` and `mb108_watch` each carried a byte-identical copy of these twenty lines and
**stored none of it** — so the number existed only inside whichever round last ran it.

Declared in `CLIP_FIELDS` at the **MEASURED** tier, because a detector read the media and
because **an undeclared key reads as `None` through `field()`** — the failure that has now cost
three rounds. An absent value reads `None`, never `0.0`: zero is what a perfectly still clip
measures, and filing an unmeasured clip as the most static thing in the library is the same
confusion the consumer rule exists to prevent.

## 3. Does it separate the 61 verdicts? **No — and per-judge is why**

59 of the 61 labelled rows now carry a stored motion value.

| | n_post | n_not | median POST | median NOT | **P** |
|---|---:|---:|---:|---:|---:|
| **POOLED** | 8 | 51 | 18.11 | 25.57 | **0.37** |
| BL-950 | 0 | 24 | — | 23.14 | *no contrast* |
| MEMEBOT-074 | 3 | 25 | **0.01** | 26.37 | **0.01** |
| MEMEBOT-086 | 5 | 2 | 26.03 | 30.50 | **0.50** |

Pooled it does not separate. Per judge it *appears* to, at P=0.01 — **in the wrong direction**,
and that is the finding:

### The judges disagree about whether static is a defect at all

**All three of MEMEBOT-074's postable clips are static graphics.**

| motion | judge | verdict | what the judge wrote |
|---:|---|---|---|
| **0.00** | MEMEBOT-074 | **post** | *"same as 21; source title top-sliced"* |
| **0.01** | MEMEBOT-074 | **post** | *"right length, right song, **static but that is the format**"* |
| **0.04** | MEMEBOT-074 | **post** | *"8s, football song on football content"* |
| 15.39–76.43 | MEMEBOT-086 | post | *"fills the frame", "hook intact"* ×5 |

MEMEBOT-098 made static infographics its **#1 defect class** — *"the ranker selected things
that are not clips"*, five of seventeen failures. MEMEBOT-074 wrote **"static but that is the
format — Post"**.

So `motion` is not failing to predict a stable target. **The target is not stable.** One judge
treats a static graphic as the format working; another treats it as the clearest possible
defect. MEMEBOT-074's P=0.01 is that disagreement, measured.

### The static class, which is the claim motion actually makes

`motion` was built to identify static graphics, not to predict postability. Tested directly —
using whether the judge *named* a static/graphic defect:

| motion < | TP | FP | FN | precision | recall |
|---:|---:|---:|---:|---:|---:|
| 0.5 / 1.0 / 2.0 / 3.0 / 5.0 | 1 | 4 | 0 | **0.20** | **1.00** |

**Only one clip in 61 was labelled static by a judge.** Recall is 1.00 on n=1, which means
nothing, and precision 0.20 is dominated by MEMEBOT-074's three accepted static graphics being
counted as false positives — by a threshold that judge would reject outright.

**The class is too rare in this label set to validate anything.** Identical at every threshold
from 0.5 to 5.0, which is itself the tell: there is no boundary to find with one positive.

## 4. What this means for BL-988's gate term

**A correction first: BL-988's gate term does not read `motion` and never did.**
`clip_postable.is_static_non_clip` is one line — `_STATIC_WORDS.search(_text(clip,
"vision_scene"))`. It matches *prose* in the vision label. The word "motion" appears once in
that entire file, inside a self-test string. **Nothing was re-deriving the number**, so there
is no re-derivation to replace.

What can be said:

- **The field is now available** to `clip_postable` at zero cost — `field(clip, "motion")` on
  92 clips today, and on any clip a future backfill reaches.
- **It is not validated, and this label set cannot validate it.** One static-labelled clip.
- **The term may still be right.** MEMEBOT-098's 0.20–0.35 vs 5–23 is a real, order-of-
  magnitude separation on the clips it looked at, and this round reproduced that scale
  (measured range across 92 clips spans 0.00 to 76.43). What is missing is not the signal —
  it is *labels that agree on whether the signal describes a defect*.
- **Gating on it today would have removed all three of MEMEBOT-074's postable clips.** That is
  the concrete cost, and it is why `clip_motion.looks_static(None)` returns **None, never
  True**: UNKNOWN never decides.

**The cheapest thing that would settle it** is not more clips — it is asking the four judges
one question: *is a static graphic postable?* The label set already records who judged what
(`ground_truth/clip_verdicts.json`), so the disagreement is now visible instead of averaged
away.
