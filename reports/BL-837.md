## 1. The tag is passed

`clip_runner.py:209` called `cg.label(tag=None, ...)`, so `TAG_GENRE`'s 38 entries had never
produced a genre. It now reads `media["found_via"]` / `media["source_hashtag"]`, with the
explicit `tag=` argument taking precedence.

Proved end to end on a real media shape:

```
media = {..., 'found_via': 'batman', 'caption': 'Title: Gladiator / Genre: Action, Historical Drama, War'}
clip_record(...) ->
  content_genre : ['action', 'historical', 'drama', 'war']
  franchise     : Batman          <- from the TAG. Nothing produced this before.
  provenance    : declared
```

**The +18 genre fill above does NOT include this.** Stored clips carry no tag, so re-labelling
can only exercise the caption path. The tag fix shows up on the next walk, and it is the only
genre source for the 21 accounts (n≥5) whose captions declare nothing at all.

## 2. The provenance tier survives

`clip_library.py` hard-coded `DERIVED`. `build_record` now takes `content_genre_source` and
`franchise_source`, defaulting to `DERIVED` — the conservative reading, so nothing ever claims
a page said something it did not.

**A trap worth recording, because my first attempt still measured `declared=0`:** the tier is
at `record["provenance"]["content_genre"]`, **not** `cg.field(rec, "content_genre_source")`.
`content_genre_source` is a plain key with no provenance entry of its own, so the consumer rule
correctly returns `None` for it. Reading it through `field()` looks right and silently yields
nothing.

## 3. Compounds split — 78 instances, no new vocabulary

```
family comedy     -> family + comedy          crime drama      -> crime + drama
romantic comedy   -> romance + comedy         historical drama -> historical + drama
war drama         -> war + drama              satirical sci-fi -> satire + sci-fi
```

Three properties, all tested:

- **A bigram pass runs first.** Hyphens flatten to spaces, so `sci-fi` and `martial arts`
  arrive as two words and would fail per-word.
- **One unknown word refuses the whole split.** `bl-themed drama`, `psychological drama` and
  `dystopian science fiction` yield nothing rather than a partial guess.
- **Adjectival aliases were required.** Compounds are written adjective-first, so without
  `romantic → romance` the split refused on the first word — which is how `romantic comedy` (8)
  was being lost.

**`animated sitcom` → genre `sitcom` + medium `animation`; `adult animation` → medium only.**
These carry both axes in one token and are the clearest demonstration that the BL-703 split is
load-bearing rather than tidy.

## 7. imdb — the premise was wrong

**There is no IMDb identifier in any caption. A `tt`-id appears on 0 of 617.** What the
templates carry is a *score*: `7.1/10 (IMDb)`, `⭐ IMDb – 6.2/10`.

So item 7's rationale — "a stable external ID fixes franchise dedup outright and gives a
downstream bot a real join key" — **does not hold, and that error is mine from BL-831**, where I
counted the label `imdb` appearing on 26.9% of clips and inferred an identifier without
checking the values.

Shipped as **`imdb_rating`** (float 0–10, provenance `DECLARED` — the page states it, we do not
verify it), **26.7% fill**. It is a quality signal, not a join key. Franchise dedup remains
unsolved by it; §5's cleaning is what actually reduced duplicates.

## Limits

- **The before/after is a re-label, not a re-walk.** No clip was rewritten, so the library on
  disk still holds the old values until the next walk. The numbers say what the new code
  *would* produce on the same captions.
- **The tag fix is unmeasured on real data.** Stored clips have no tag; its effect is proved
  functionally (`found_via: batman → franchise Batman`) and by `TAG_GENRE`'s 38 entries, not by
  a fill-rate delta.
- **Genre fill rose only 2.9 points.** The compound/vocabulary work adds precision to clips
  that already had a genre far more than it adds new clips — the 71.5% gap is supply
  composition (21 accounts declare nothing), which no parser fixes.
- **`sports` measured 3 on re-label against BL-831's 2** — the split now catches an instance the
  whole-token pass missed. Small numbers move.
- **Franchise values are cleaned, not canonicalised.** `Iron Man 2 (2010)` and `Iron Man 2`
  remain distinct; only invisible-character and foreign-label duplicates collapse.
- **`imdb_rating` is unverified by construction** — it is whatever the page typed.
